RELEASE TRACKING

What this preview can prove.

Useful for layout, discoverability, typing ergonomics and feature direction. Not a substitute for Android device tests.

Previewed interactions

QWERTY-style touch entry, deletion, shift and symbols, emoji-like sticker gallery, Unicode-style experiments, dummy voice cleanup, and an editable Pre-screen draft with approval.

Not exercised here

Android IME permissions and lifecycle, real predictions and autocorrect, native sticker MIME insertion, Groq or OpenAI network transcription, provider key security, OS clipboard, voice capture, APK packaging and backup/restore.

Engineering checkpoints

Foundation + clipboardNeeds security fixes and Android tests
